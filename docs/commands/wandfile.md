# wand wandfile

Manage system configuration with wandfile manifests.

## Syntax

```bash
wand wandfile <subcommand> [OPTIONS]
```

## Description

The `wandfile` command manages declarative system configuration. A wandfile defines all packages (CLI and GUI) and dotfiles for your system, enabling reproducible development environment setup.

## Subcommands

- `install` - Install packages from a wandfile
- `check` - Verify all packages are installed
- `dump` - Generate wandfile from installed packages
- `init` - Create a new wandfile
- `validate` - Check if wandfile is valid
- `show` - Display wandfile summary
- `update` - Update packages from wandfile

## Usage

### Install from wandfile

```bash
wand wandfile install [SOURCE]
```

**Arguments:**
- `[SOURCE]` - Wandfile path, URL, or GitHub shorthand (default: `.`)

**Flags:**
- `-s, --source` - Wandfile source (alternative to positional argument)

### Check wandfile

```bash
wand wandfile check [PATH]
```

**Arguments:**
- `[PATH]` - Path to wandfile (default: `.`)

**Flags:**
- `-p, --path` - Path to wandfile

### Dump installed packages

```bash
wand wandfile dump [OUTPUT]
```

**Arguments:**
- `[OUTPUT]` - Output file path (default: stdout)

**Flags:**
- `-o, --output` - Output file path

### Initialize wandfile

```bash
wand wandfile init
```

Creates a new `wandfile.yaml` in the current directory with common packages.

### Validate wandfile

```bash
wand wandfile validate [PATH]
```

**Arguments:**
- `[PATH]` - Path to wandfile (default: `.`)

**Flags:**
- `-p, --path` - Path to wandfile

### Show wandfile

```bash
wand wandfile show [PATH]
```

**Arguments:**
- `[PATH]` - Path to wandfile (default: `.`)

**Flags:**
- `-p, --path` - Path to wandfile

### Update from wandfile

```bash
wand wandfile update [PATH]
```

**Arguments:**
- `[PATH]` - Path to wandfile (default: `.`)

**Flags:**
- `-p, --path` - Path to wandfile

## Wandfile Format

### Modern Format (Recommended)

The modern wandfile format uses `formulas` and `symlinks` fields:

```yaml
# Complete development environment configuration
# Install with: wand wandfile install

formulas:
  - name: zsh
    version: latest

  - name: zsh-syntax-highlighting  # version defaults to latest

  - name: zsh-autosuggestions

  - name: neovim
    version: 0.9.5

symlinks:
  # Shell configurations
  .zshrc: shell/zshrc
  .zshenv: shell/zshenv
  .bashrc: shell/bashrc

  # Git configurations
  .gitconfig: git/gitconfig
  .gitignore_global: git/gitignore_global

  # Neovim
  .config/nvim/init.lua: nvim/init.lua
  .config/nvim/lua: nvim/lua

  # Tmux
  .tmux.conf: tmux/tmux.conf
```

**Formulas:**
- Unified list for all package types (CLI, GUI, shell plugins)
- Version is optional (defaults to `latest`)
- Supports all formula types including shell plugins

**Symlinks:**
- Direct mapping: `target: source`
- Source paths are relative to `~/.dotfiles/`
- Target paths are relative to `~/`
- Automatically creates parent directories
- Backs up existing files with `.wand-backup` extension

### Legacy Format (Still Supported)

```yaml
# CLI packages
cli:
  - name: <package-name>
    version: <version|latest>
  - name: <package-name>
    version: <version|latest>

# GUI applications
gui:
  - <app-name>
  - <app-name>

# Dotfiles configuration
dotfiles:
  repo: <github-shorthand|git-url>
  symlinks:
    <target>: <source>
    <target>: <source>
```

## Use Cases

### Complete System Setup

Create a wandfile for your development environment and share across machines:

```bash
# On machine 1: create wandfile from current system
wand wandfile dump -o my-setup.yaml

# On machine 2: install everything
wand wandfile install my-setup.yaml
```

### Team Development Environment

Share a wandfile in your project repository:

```bash
# .wandfile in project root
cli:
  - name: node
    version: 20.10.0
  - name: terraform
    version: 1.6.0
  - name: kubectl
    version: 1.28.0

# Team members run:
cd project/
wand wandfile install
```

### Multiple Profiles

Create different wandfiles for different purposes:

```bash
wand wandfile install ~/dotfiles/work.yaml
wand wandfile install ~/dotfiles/personal.yaml
wand wandfile install ~/dotfiles/gaming.yaml
```

## Error Handling

Common errors and solutions:

- `Failed to load wandfile` - Check file path and YAML syntax
- `Package not found in formulas` - Package doesn't exist in wand formulas
- `Invalid version specified` - Check version format or availability
- `Repository not accessible` - Check dotfiles repository URL
- `Validation failed` - Run `wand wandfile validate` to see errors
